=====================================
Pembaruan ini dilakukan pada skrip orisinal repositori untuk menyesuaikan skema nama kolom (kolom `id` berubah menjadi `recording_id`, dan `recordist` berubah menjadi `author` sesuai dengan format baru BirdCLEF).

1. File: `src/evaluate.py`
--------------------------
Garis awal:
```python
        row = {
            "query_id": query_df.iloc[i]["id"],
            "species_key": query_df.iloc[i]["species_key"],
            "recordist": query_df.iloc[i]["recordist"],
```
Diubah menjadi:
```python
        row = {
            "query_id": query_df.iloc[i]["recording_id"],
            "species_key": query_df.iloc[i]["species_key"],
            "recordist": query_df.iloc[i].get("author", "Unknown"),
```
