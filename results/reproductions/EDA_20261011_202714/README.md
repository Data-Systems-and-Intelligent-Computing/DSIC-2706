# EDA — Inventaris audio fisik

EDA formal untuk 3.396 audio fisik target, unknown, dan noise ITERA.

- `tables/physical_audio_inventory.csv`: inventaris setiap file.
- `tables/summary_by_source.csv`: ringkasan sumber dan durasi.
- `tables/target_species_summary.csv`: jumlah rekaman per spesies target.
- `tables/noise_location_summary.csv`: jumlah noise per folder lokasi.
- `figures/eda_overview.png`: grafik siap dilihat atau di-screenshot.
