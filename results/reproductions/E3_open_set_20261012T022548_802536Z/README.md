# E3 — Open-set frozen threshold

Thresholds are calibrated only from separate clean calibration data and remain frozen across every test SNR. E2 known-query scores are joined by `query_id`, never CSV row order.

[Ambang hasil kalibrasi](tables/frozen_thresholds.csv) untuk setiap representasi adalah R0 = 0,995752, R1 = 0,897416, R2 = 0,702785, R3 = 0,488838. [Tabel pengujian](tables/threshold_transfer.csv) memuat penerimaan target dan kontrol pada setiap kondisi.
