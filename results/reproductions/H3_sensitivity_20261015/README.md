# H3 sensitivity reanalysis

Stored E4 raw CSVs only; no audio mixing, inference, or edits to the original run.

Both absolute mAP@10 swing and relative-retention swing are reported for all five locations and without Kebun Raya. Range is computed within each repeat before averaging repeats. Paired query bootstrap uses 10,000 draws by default; intervals are exploratory and conditional on fixed noise/location samples.
