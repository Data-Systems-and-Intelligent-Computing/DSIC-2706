# Cache embedding bersih

Artefak ini hanya menyimpan embedding gallery dan query bersih dari manifes aktif. Artefak ini bukan hasil E4 dan tidak memuat pencampuran derau, metrik kondisi derau, atau kesimpulan penelitian.

[Vektor R3](clean_embeddings_R3.npz) memuat 673 rekaman galeri dan 311 kueri acuan. [Metadata](metadata.json) mencatat identitas sumber dan mAP@10 acuan 0,0211.
