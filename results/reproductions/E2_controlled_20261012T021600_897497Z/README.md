# E2 — Controlled ITERA-noise robustness

Each `raw/*.csv` contains all 311 active queries for one representation and one condition. Gallery embeddings are the verified clean caches; noisy query embeddings are extracted with a deterministic physical-noise segment. Completed conditions can be resumed only after their CSV and sidecar JSON pass validation.

Pada −5 dB, [ringkasan E2](tables/e2_snr_robustness.csv) mencatat mAP@10 BirdNET 0,4832 dan retensi 75,88% terhadap kondisi acuan pada 311 kueri.
