# EDA — Inventaris audio fisik

- `tables/physical_audio_inventory.csv`: detail setiap audio.
- `tables/summary_by_source.csv`: ringkasan sumber.
- `tables/target_species_summary.csv`: ringkasan spesies.
- `tables/noise_location_summary.csv`: lokasi noise.
- `figures/eda_overview.png`: gambar EDA.

[Inventaris fisik](tables/physical_audio_inventory.csv) mencakup 3.396 berkas. [Rincian per sumber dan peran](tables/summary_by_source.csv) memisahkan berkas eksperimen dari berkas lain yang ditemukan pada inventaris.
