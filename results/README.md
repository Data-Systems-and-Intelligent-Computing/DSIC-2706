# Results

`reproductions/` adalah artefak eksperimen asal yang tervalidasi. Setiap run mempertahankan `metadata.json`, tabel, gambar, dan data per-query masing-masing.

`figures/` dan `tables/` adalah salinan bahan laporan yang mudah dicari. Daftarnya, lokasi sumber, checksum SHA-256, dan tujuan setiap file ada di `report_materials_manifest.json`. Salinan ini tidak menggantikan atau mengubah artefak asal.

Tabel E5 yang sangat besar tetap berada di sumbernya agar hasil per-query tidak diduplikasi tanpa kebutuhan laporan:

- `reproductions/E5_diagnostics_20261012T091512_868500Z/tables/all_query_diagnostics.csv`
- `reproductions/E5_diagnostics_20261012T091512_868500Z/tables/failure_cases.csv`

Untuk hasil RQ dan H1–H5, baca `docs/RESULTS_RQ_HYPOTHESES_2026-10-12.md` dan tabel `tables/23_statistics_rq_hypothesis_matrix.csv`.
