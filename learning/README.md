# Learning

Mulai dari [panduan penelitian dalam bahasa sehari-hari](PANDUAN_PENELITIAN_BAHASA_SEHARI_HARI.md) untuk memahami judul, data, RQ, hipotesis, E0–E5, hitungan, hasil, kontribusi, serta persiapan bimbingan dosen 2. Panduan belajar ini tidak mengganti rumusan resmi penelitian.

Latihan 01–06 adalah jalur belajar bertahap: mengenal file audio, menyamakan bentuk audio, MFCC, retrieval kecil, inspeksi panggilan, dan audit manifes.

[Arsip teori dan ilustrasi](teori_dasar/README.md) menyimpan draf serta panduan terdahulu.

Latihan tidak menghasilkan bukti E0–E5 dan tidak mengubah audio. Catatan pembelajaran ada di `CATATAN_BELAJAR.md`; eksperimen resmi dipetakan dari `experiments/` dan divisualkan di `notebooks/`.

Untuk persiapan bimbingan, [paket belajar](PAKET_BELAJAR_UJIAN/README.md) memuat contoh hitungan. Cocokkan istilah dan empat rumusan masalah dengan [Bab I](../paper/template_ta_latex/chapters/bab1.tex), lalu telusuri langkah E0–E5 di [Bab III](../paper/template_ta_latex/chapters/bab3.tex).
